# Jiaying Chen -- How AI Changes Developers' Daily Tasks

Target speaking time: approximately 35-40 seconds.

## Script

AI is also changing developers' daily tasks. It can help draft code, explain functions, and suggest tests.

For example, AI might generate a login feature, but a developer must still check whether it handles incorrect passwords safely.

In Stack Overflow's 2025 survey, about 46 percent of respondents distrusted the accuracy of AI outputs.

Our conclusion is that job applicants should demonstrate not only coding ability, but also the ability, but also the ability to review, debug, and test AI-generated code.

## Source
https://survey.stackoverflow.co/2025/ai

## Notes
- The login example is illustrative, not an actual experiment.
- About 46% is rounded from 45.7%.
- The conclusion is our interpretation, not a hiring statistic.
